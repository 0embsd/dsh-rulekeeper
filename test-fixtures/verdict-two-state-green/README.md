# 两态样本 · 绿态：新口径（改动后）

- 被测纪律：`CRED-FRESHNESS` —— 判据必须落在被测对象自身的事实上，凭据必须可复核。
- 新口径（绿）：账本每一行的 `evidence` 逐项判①引用的仓库内对象必须存在；②必须有对象锚点
  （存在的仓库内文件 / `key=value` / 具名错误码 / 指纹），只写"整份报告 ok"不算；
  ③**落点级故障与对象级判据分开报**（`LEDGER_BAD_ROW` / 账本缺失各自成码，不混成一个结论）。
- 对象级与落点级的分界：账本读不动 ⇒ 判"判定不可信"（exit 2），**不是**判通过，也不是判对象违规。
- 旧口径红样本：见 `verdict-two-state-red`。
