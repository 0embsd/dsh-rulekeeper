# 静态红样本 B：计划行**晚于**改动时刻（先做后补 ⇒ 不算事前设计）

为什么单列这一条：`plan-fx-stale` 测的是"计划太旧"，本条测的是**时序方向**（`plan.ts > now`）——
两条判别路径不同，缺一条就少一半覆盖。

期望：observe 档 **exit 0** + `PLAN_FINDINGS=1`（`晚于改动时刻`）；`RULEKEEPER_PLAN_MODE=armed` 时 **exit 1**。

⚠ 我第一版把这条写成"2 天前的计划"想测过窗 —— 那其实**落在 24h 窗口边界内**（`≤` 含等于），
实测 `PLAN_FINDINGS=0` 才发现；这也说明**样本必须跑一遍才知道它到底测什么**（规则 53 的精神）。
