# 两态样本 · 红态：旧口径（改动前）

- 被测纪律：`CRED-FRESHNESS` —— 判据必须落在被测对象自身的事实上，凭据必须可复核。
- 旧口径（红）：拿**聚合结论**当对象级判据 —— "落点里任意一条 finding 命中"就宣布"判据拦住了载体"，
  于是只要有一个坏 `config.json`，**根本没被保护的文件**也能拿到 `EFFECT_VERIFIED`；
  凭据只写"整份报告 ok / 全表绿"，无法指认到具体对象 ⇒ 事后没有任何东西可以复核。
- 新口径（绿）：见 `verdict-two-state-green`。
- 可重跑的构造方式：检查器 `scripts/checkers/ledger-live-verdict.mjs` 每次运行都会**现造**一棵
  "凭据指向不存在的对象 + 只有聚合断言"的临时账本，并断言它必须被判红。
